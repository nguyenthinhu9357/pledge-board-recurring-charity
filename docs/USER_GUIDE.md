# User guide

## Create and fund a pledge

1. Choose the charity, amount, and due date.
2. Connect Freighter and confirm it is on Stellar Mainnet.
3. Review the charity address, amount, and contract before signing `create_pledge`.
4. Fund the pledge with the displayed native XLM amount.
5. Keep the successful transaction hash as proof.

Only the designated charity can authorize release. Refund becomes available after
the contract deadline when the pledge has not been released.
