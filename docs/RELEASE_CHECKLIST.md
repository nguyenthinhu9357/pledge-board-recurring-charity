# Release checklist

- [ ] Web tests, Rust tests, type checking, lint, and build pass.
- [ ] Contract ID and native XLM SAC match the deployment manifest.
- [ ] Public app opens without authentication.
- [ ] Donor, charity, amount, and deadline are visible before signing.
- [ ] Fund, release, refund, and cancellation states are unambiguous.
- [ ] Duplicate hashes and repeated contract calls are handled safely.
- [ ] Latest functional transaction and README evidence are current.
- [ ] Previous deployment and rollback owner are recorded.
