# Incident response

Critical incidents include leaked signer material, wrong charity destination, or
unexpected contract transfer. High-severity incidents include blocked refunds,
incorrect deadlines, duplicate funding, or Mainnet/Testnet confusion.

Pause new pledge actions, preserve hashes and events, identify affected pledge IDs,
and communicate a precise user action. Resume only after reproducing the cause,
adding a regression test, and verifying contract plus production configuration.
