# Security policy

Report vulnerabilities privately to the maintainers with reproduction steps,
affected contract function or route, and expected impact. Do not disclose wallet
secrets, seed phrases, database credentials, or signed envelopes.

Janji uses external wallet authorization and a Mainnet Soroban contract. Changes to
donor authorization, charity destination, deadline logic, token transfer, release,
refund, or cancellation require an additional reviewer and contract regression tests.
